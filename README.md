# Einstein — เรียนฟิสิกส์อนุภาคแบบ Interactive

เว็บไซต์สำหรับเรียน 8 บท แบ่งเป็น 2 กลุ่ม

- **ฟิสิกส์คลาสสิก:** 01 รากฐานและกลศาสตร์ · 02 สสารและอุณหพลศาสตร์ · 03 คลื่นและทัศนศาสตร์ · 04 ไฟฟ้าสถิต
- **ฟิสิกส์ยุคใหม่:** 05 อนุภาคในสนามแม่เหล็ก · 06 คลื่นแม่เหล็กไฟฟ้า · 07 ฟิสิกส์อะตอม · 08 ฟิสิกส์นิวเคลียร์

แต่ละบทมี **บทเรียน** (อธิบายแบบ Feynman + กล่องผู้เชี่ยวชาญตรวจทาน) **การจำลอง 3 มิติ** (Three.js) และ **แบบฝึกหัด** 3 ระดับ (20 ข้อต่อบท) แนว TPAT3

**กำเนิดจักรวาล:** คลิกอะตอม 3 มิติข้างหัวข้อในหน้าแรก เว็บจะเปลี่ยนเป็นโหมดมืดแล้วเล่นภาพยนตร์สั้นแบบโต้ตอบได้ ตั้งแต่บิกแบงจนถึงโลกและสิ่งมีชีวิต (~105 วินาทีที่ความเร็ว 1×) พร้อมเสียงที่สร้างสดด้วย Web Audio — รายละเอียดในหัวข้อ [กำเนิดจักรวาล](#กำเนิดจักรวาล) ปุ่มดวงจันทร์/ดวงอาทิตย์มุมขวาบนสลับโหมดสว่าง–มืด

## เปิดใช้งาน

**วิธีที่ 1 — ดับเบิลคลิก `index.html`**
ทุกอย่างทำงานได้ทันทีแบบออฟไลน์ (Three.js, MathJax และ Tailwind CSS ถูกเก็บไว้ในโปรเจกต์แล้ว)
ถ้าไม่มีอินเทอร์เน็ต ฟอนต์จะเปลี่ยนไปใช้ฟอนต์ของระบบแทน

**วิธีที่ 2 — รันผ่านเว็บเซิร์ฟเวอร์ (แนะนำตอนพัฒนา)**

```bash
npm install        # ครั้งแรกครั้งเดียว
npm run dev        # build Tailwind แล้วเปิด http://localhost:5173
```

ใช้ VS Code ก็ได้: ติดตั้งส่วนขยาย Live Server แล้วคลิกขวาที่ `index.html` → Open with Live Server

## แก้ไขสไตล์

- คลาส Tailwind ใช้ได้ใน `index.html` และไฟล์ใน `assets/js/`
- หลังเพิ่มคลาส Tailwind ใหม่ ให้รัน `npm run build:css` (หรือ `npm run watch:css` ระหว่างแก้)
- สไตล์เฉพาะของเว็บ (สีประจำบท บทเรียน แผงควบคุม แบบฝึกหัด) อยู่ที่ `assets/css/style.css`

## เพิ่มเนื้อหา

- **แบบฝึกหัดใหม่:** ดูหัวข้อ [แบบฝึกหัด](#แบบฝึกหัด) ด้านล่าง
- **แก้บทเรียน:** แก้ใน `<template id="lec-...">` ของ `index.html` หัวข้อ `<h2 id="...">` จะขึ้นในสารบัญอัตโนมัติ
- **ลิงก์ข้ามบทไปหัวข้อ:** ใช้ `<a href="#<id>?s=s3">` (เช่น `#estat?s=s3`) เปิดบทเรียนแล้วเลื่อนไปหัวข้อ `s3` ลิงก์แบบเดิม (`#<id>`, `#<id>-sim`, `#<id>-quiz`) ทำงานเหมือนเดิม
- **บทใหม่:** เพิ่มใน `MODS` (`data/modules.js`) + template บทเรียน + ชุดแบบฝึกหัด (`data/practice/<id>.js`) + ฟังก์ชันจำลองใน `sims/` แล้วลงทะเบียนใน `SIMS` ภายใน `renderSim()` ของ `app.js`

## แบบฝึกหัด

แต่ละบทมีแบบฝึกหัด 20 ข้อ แบ่งเป็น 3 ระดับ (7 / 7 / 6 ข้อ) ที่แท็บ "แบบฝึกหัด" (`#<id>-quiz`)

| ระดับ | ฝึกอะไร |
|---|---|
| 1 · เข้าใจแนวคิด | เลือกตอบ ระบบอธิบายเหตุผลของตัวเลือกที่เลือกผิด |
| 2 · คำนวณ | แทนค่าในสูตรและจัดหน่วย พิมพ์คำตอบเป็นตัวเลข (สุ่มตัวเลขใหม่ทุกครั้ง) |
| 3 · โจทย์ประยุกต์ | โจทย์หลายขั้นตอนแนว TPAT3 มีคำใบ้เป็นขั้นและเฉลยวิธีทำ |

**พิมพ์คำตอบ:** ช่องคำตอบรับรูปแบบเหล่านี้ (ค่าเดียวกันทั้งหมด)

- `0.021` · `2.1e-2` · `2.1×10^-2` · `2.1 x 10^(-2)` · `2.1 × 10⁻²`
- หลักพันคั่นด้วยจุลภาคหรือเว้นวรรค: `12,000` หรือ `12 000`
- เครื่องหมายลบแบบ Unicode (`−`)
- ต่อท้ายด้วยหน่วยหรือสัญลักษณ์ได้ เช่น `35 m/s`, `30°`, `5%`

ถือว่าถูกเมื่อคลาดเคลื่อนไม่เกิน ±2 % (บางข้อในบทนิวเคลียร์เข้มกว่านั้น กำหนดไว้ในข้อนั้น)

**ความคืบหน้า** เก็บในเบราว์เซอร์ของผู้ใช้ (localStorage) แยกรายบท ไม่ส่งออกไปที่ใด มีปุ่ม "ล้างความคืบหน้าบทนี้" ท้ายหน้าแผนที่ระดับของแต่ละบท เปลี่ยนเบราว์เซอร์หรือล้างข้อมูลเว็บแล้วจะเริ่มใหม่

**เพิ่มหรือแก้ข้อ**

1. แก้ `assets/js/data/practice/<id>.js` ตามโครงสร้างของข้อที่มีอยู่ในไฟล์เดียวกัน (อธิบาย schema ไว้ใน `docs/superpowers/specs/2026-11-20-practice-ladder-design.md`)
2. เขียนหรือแก้ค่าอ้างอิงด้วย Python ใน `tests/practice-ref/compute_<id>.py` แล้วสร้างไฟล์ผลลัพธ์

   ```bash
   python3 tests/practice-ref/compute_<id>.py > tests/practice-ref/<id>.json
   ```

3. รัน `npm test` ตัวตรวจสอบจะเทียบคำตอบของทุกข้อกับค่าอ้างอิง ตรวจรูปแบบสมการ คำใบ้ และเฉลย
4. บันทึกผลการตรวจเนื้อหาไว้ที่ `docs/superpowers/content-review/<id>.md`

## กำเนิดจักรวาล

**การควบคุม**

| ทำอะไร | วิธี |
|---|---|
| เล่น / หยุด | ปุ่ม ▶ หรือ Space |
| ยุคก่อน / ถัดไป | ปุ่ม ‹ › หรือ ← → |
| เลื่อนเวลา | ลากแถบเวลา (สเกลลอการิทึมแบ่งช่วง ขีดสีทองคือจุดเริ่มแต่ละยุค) |
| ความเร็ว | 1× / 2× / 5× |
| หมุน / ซูมกล้อง | ลากเมาส์ / ล้อเมาส์ (กล้องกลับสู่เส้นทางเดิมเมื่อขึ้นยุคใหม่) |
| กริดกาลอวกาศ, ป้ายกำกับอนุภาค | ปุ่ม "กริด", "ป้าย" |
| ปิด | ปุ่ม ✕ หรือ Esc |

**เสียง:** เปิดเองเมื่อคลิกอะตอม (เบราว์เซอร์ยอมให้เล่นเสียงหลังผู้ใช้คลิกเท่านั้น ถ้าปุ่มขึ้นว่า "แตะเพื่อเปิดเสียง" ให้แตะหนึ่งครั้ง) ปุ่ม "เสียง" ปิด/เปิดได้ และเว็บจำค่าไว้ครั้งต่อไป

**ระดับคุณภาพ:** เริ่มที่ high บนคอมพิวเตอร์ (อนุภาค 100,000 จุด, bloom เต็ม) และ medium บนจอสัมผัส (50,000 จุด) ถ้าเฉลี่ยเฟรมช้ากว่า 22 ms ต่อเนื่อง 2 วินาที จะลดเป็น medium → low (20,000 จุด, ไม่มี chromatic aberration) อัตโนมัติ ผู้ที่ตั้ง "ลดการเคลื่อนไหว" ในระบบจะไม่มีแสงวาบ เกรน และกล้องสั่น

**ตรวจ fps บนเครื่องจริง (Chrome):** เปิดเว็บ → F12 → Ctrl+Shift+P พิมพ์ "Show frame rendering stats" → คลิกอะตอม แล้วดูค่า FPS ในแต่ละยุค ถ้าต่ำกว่า ~45 fps ให้แจ้งยุคที่ช้า

**แบบจำลองฟิสิกส์:** ΛCDM แบบแบน พารามิเตอร์ Planck 2018 (H₀ = 67.4 km/s/Mpc, Ωm = 0.315, Ωr ≈ 9.1×10⁻⁵, T₀ = 2.7255 K) อินทิเกรตสมการฟรีดมันน์ได้อายุเอกภพ 13.79 พันล้านปี, a ที่ยุครวมตัว ≈ 1/1100 และ T ≈ 2,900 K ช่วงการพองตัว (10⁻³⁶–10⁻³² s, ≥ e⁶⁰) และ reheating ขึ้นกับแบบจำลอง HUD จึงแสดงอุณหภูมิช่วงนั้นด้วยเครื่องหมาย "≈" ภาพทุกเฟรมเป็นฟังก์ชันของเวลาเท่านั้น (เลื่อนกลับมาที่เวลาเดิมได้ภาพเดิม) การขยายของกาแล็กซีเป็นแบบสม่ำเสมอบนโครงตาข่าย comoving ไม่มีจุดศูนย์กลาง

**ทดสอบ:** `npm test` (Node: ฟิสิกส์จักรวาล + ฟิสิกส์ไฟฟ้าสถิต + แบบฝึกหัด) และ `for f in tests/e2e/test_*.py; do python3 $f || exit 1; done` (เบราว์เซอร์ ต้องมี Playwright + Chrome) รันไฟล์เดียวหรือบางเทสต์ได้ เช่น `python3 tests/e2e/test_estat.py test_cross_links`

## ความถูกต้องของเนื้อหา

- ค่าคงที่อ้างอิง CODATA 2022 (NIST)
- ลำดับเวลาจักรวาล: อายุ 13,787 ± 20 ล้านปี (Planck 2018), นิวเคลียสแรกใน ~20 นาที (H ~75% / He ~25% โดยมวล), อะตอมแรก ~380,000 ปี, โลก 4,540 ล้านปี, สิ่งมีชีวิตอย่างน้อย 3,500 ล้านปี
- เส้นบาลเมอร์จากการจำลอง (656.4, 486.2, 434.1, 410.2 nm) ตรงกับค่าวัดจริง 656.3, 486.1, 434.0, 410.2 nm ภายใน 0.1 nm
- การจำลองย่อเวลาและขยายบางขนาดเพื่อให้มองเห็นได้ และระบุไว้ในแผงควบคุมทุกครั้ง
