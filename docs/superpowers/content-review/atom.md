# บันทึกตรวจเนื้อหา · แบบฝึกหัดฟิสิกส์อะตอม (atom)

วิธีตรวจของเจ้าของ: อธิบายแบบ Feynman ในมุมผู้เรียน → ผู้เชี่ยวชาญตรวจกับฟิสิกส์ที่ยอมรับ → แก้และวนซ้ำ
ข้อละหนึ่งบรรทัด: **F** = สิ่งที่การอธิบายในมุมผู้เรียนเผยให้เห็น · **E** = สิ่งที่ผู้เชี่ยวชาญยืนยัน/แก้
คำตอบระดับ 2–3 ตรวจซ้ำแยกอิสระด้วย `tests/practice-ref/compute_atom.py` ซึ่งใช้เส้นทางคนละแบบกับ JS: พลังงานโฟตอนของไฮโดรเจนจากสูตรริดเบิร์ก \(R_H = 1.097\times10^7\ \text{m}^{-1}\) (ไม่ใช่ \(13.6(1/n_f^2 - 1/n_i^2)\)); 2-01 ใช้ระดับเดิม + พลังงานโฟตอนที่พิมพ์ในโจทย์ แล้วหาระดับที่ตกลงไป (และยืนยันว่าทุกคู่ที่สุ่มได้ ผลบวกดิบอยู่ในเกณฑ์ 2%); 2-02 หาพลังงานยึดจากรัศมีที่พิมพ์ในโจทย์ผ่านพลังงานคูลอมบ์ \(-ke^2/2r\) (ไม่ผ่าน \(n\)); พลังงานโฟตอนโฟโตอิเล็กทริกจาก \(hf\), \(f = c/\lambda\); \(f_0\) แบ่งครึ่งช่วงบน \(hf = W\); เดอ บรอยล์จาก \(h/\sqrt{2mK}\) (ไม่ผ่าน \(v\)); อัตราเร็ว 3-02 แบ่งครึ่งช่วงบน \(\tfrac12mv^2 = K\); 3-01 ไล่ทุกการกระโดดลงจากระดับที่ไปถึงแล้วเลือกยาวสุด; 3-04 จากเงื่อนไขคลื่นนิ่ง \(2\pi r_3 = 3\lambda\) (ไม่ใช่ \(h/mv_3\)) · ต่างจาก JS ไม่เกิน 0.34%
ขอบเขต: ใช้เฉพาะสิ่งที่ `lec-atom` สอน: ทอมสัน/รัทเทอร์ฟอร์ด (ส่วนใหญ่ผ่านตรง, นิวเคลียส ~\(10^{-15}\) m, อะตอม ~\(10^{-10}\) m, แอลฟาหนักกว่าอิเล็กตรอน ~7300 เท่า, ปัญหาการแผ่รังสีแบบดั้งเดิม), โบร์ (\(r_n = n^2a_0\), \(E_n = -13.6/n^2\), \(v_n \approx 2.19\times10^6/n\), \(hf = E_i - E_f\), ไอออไนเซชัน), สเปกตรัมเส้น (1240/ΔE, ริดเบิร์ก, ชื่ออนุกรมตามตาราง, \(n(n-1)/2\), เส้นดูดกลืน), โฟโตอิเล็กทริก (\(E_{k,\max} = hf - W\), \(f_0 = W/h\), \(eV_s = E_{k,\max}\), ความเข้ม vs ความถี่), เดอ บรอยล์ (\(\lambda = h/mv\), เดวิสสัน–เจอร์เมอร์, \(2\pi r = n\lambda\)) · ใช้ \(E_k = \tfrac12mv^2\) จากบทกลศาสตร์ · ไม่ใช้ไอออนคล้ายไฮโดรเจน (Z), สัมพัทธภาพ, ค่าคงที่ของคูลอมบ์ในโจทย์
ค่าคงที่ที่ระบุในโจทย์ทุกข้อที่ใช้: \(E_n = -13.6/n^2\) eV, \(a_0 = 0.0529\) nm, \(v_n \approx 2.19\times10^6/n\) m/s, \(hc \approx 1240\) eV·nm, \(h = 6.63\times10^{-34}\) J·s, \(e = 1.6\times10^{-19}\) C, \(m_e = 9.11\times10^{-31}\) kg
