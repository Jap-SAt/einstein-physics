# บันทึกตรวจเนื้อหา · ไฟฟ้ากระแสและวงจร (circuit)

วิธีตรวจของเจ้าของ: อธิบายแบบ Feynman ในมุมผู้เรียน → ผู้เชี่ยวชาญตรวจกับฟิสิกส์ที่ยอมรับ → แก้และวนซ้ำ
บรรทัดละหนึ่งเรื่อง: **F** = สิ่งที่การอธิบายในมุมผู้เรียนเผยให้เห็น · **E** = สิ่งที่ผู้เชี่ยวชาญยืนยัน/แก้
ค่าคงที่ที่ใช้ทั้งบท (ระบุในโจทย์ทุกข้อที่ใช้): \(e = 1.6\times10^{-19}\) C · สภาพต้านทานใช้เฉพาะที่โจทย์ให้มา (นิโครม \(1.1\times10^{-6}\) Ω·m) · ความหนาแน่นอิเล็กตรอนอิสระของทองแดง \(8.5\times10^{28}\) m⁻³ ให้ในโจทย์
ข้อตกลงทั้งบท: กระแสตามข้อตกลง (ทิศประจุบวก) และบอกทุกครั้งที่อิเล็กตรอนวิ่งสวน · ศัพท์ แรงเคลื่อนไฟฟ้า (ε) / ความต่างศักย์ระหว่างขั้ว (V) / ความต้านทานภายใน (r) ตรงกับการจำลอง · คำว่า “ทิศที่สมมุติ” ใช้เฉพาะหัวข้อเคอร์ชอฟฟ์ (การจำลองใช้ “ทิศกระแสตามข้อตกลง”) · RC: ชาร์จ \(\tau = (R + r)C\) (r ของแบตเตอรี่อยู่ในวง), คายผ่าน R อย่างเดียว \(\tau = RC\), ตัวเก็บประจุอุดมคติ ตรงกับ `Circuit.tau` ในการจำลอง
ขอบเขต: ไม่ใช้แม่เหล็กหรือการเหนี่ยวนำ (เทสต์ `test_lecture_content` ห้ามคำว่า แม่เหล็ก/เหนี่ยวนำ ในบทเรียน) ไม่ใช้แคลคูลัส (ผลเฉลย RC ยกมาโดยไม่พิสูจน์) ไม่มีสารกึ่งตัวนำ

## บทเรียน (`lec-circuit`)

| หัวข้อ | บันทึก |
|---|---|
| ย่อหน้านำ | F: ผู้เรียนมาจากบทไฟฟ้าสถิต จึงบอกตั้งแต่ต้นว่า V ในวงจรคือ V เดียวกับ estat s4 และ C ใน RC คือตัวเดียวกับ estat s5 (สเปก §2 ข้อ 7) และเปิดด้วยปริศนา “ไฟติดทันทีแต่อิเล็กตรอนช้ากว่ามด” ที่ s1 ตอบ · E: ความเร็วลอยเลื่อน ~0.07 mm/s ช้ากว่ามดเดิน (~cm/s) มากจริง |
| s1 กระแสไฟฟ้าและแรงเคลื่อนไฟฟ้า | F: ผู้เรียนนึกว่าแบตเตอรี่เป็น “ถังประจุ” ที่ปล่อยประจุออกไปใช้ จึงเขียนว่าประจุมีอยู่ในสายแล้ว แบตเตอรี่ให้*พลังงาน* และสิ่งที่หมดคือสารเคมี; คำว่า “แรง” ในแรงเคลื่อนไฟฟ้าชวนเข้าใจผิด จึงบอกตรง ๆ ว่า ε ไม่ใช่แรง · E: \(I = Q/t\), 1 A = 1 C/s, \(I/e\) อนุภาคต่อวินาที, กระแสตามข้อตกลง (นอกแบตเตอรี่ + → −, ในแบตเตอรี่ที่จ่ายกระแส − → +), อิเล็กตรอนสวน, อิเล็กโทรไลต์ไอออนสวนกันแต่กระแสทิศเดียว, \(I = nev_dA\) (พิสูจน์จากปริมาตร \(Av_dt\)), สนามแผ่ไปเร็วใกล้แสง, \(\varepsilon = W/q\) (งานของแหล่งกำเนิดต่อประจุจาก − ไป + ภายใน), \(V = \varepsilon - Ir\) ใช้ตอนจ่ายกระแส ยืนยัน; รอบตรวจที่ 2: “อิเล็กตรอนไปซ้ายให้ผลเหมือนประจุบวกไปขวา*ทุกประการ*” เกินจริง (ปรากฏการณ์ฮอลล์ซึ่งเป็นผลทางแม่เหล็กแยกได้) จำกัดเป็น “สำหรับเรื่องกระแส ศักย์ และพลังงานในบทนี้”; “ภายในแบตเตอรี่กระแสไหล − → +” จริงเฉพาะตอนจ่ายกระแส เติม “ที่กำลังจ่ายกระแส” (ตอนถูกอัดประจุอยู่ใน s4); อุปมา: ลูกแก้วในท่อ (บอกขอบเขต: ส่งแรงด้วยการชน ส่วนลวดส่งด้วยสนาม), ท่อน้ำ + ปั๊ม (บอกขอบเขต: ท่อแตกน้ำทะลัก แต่สายขาดประจุไม่ไหลออก และอิเล็กตรอนไหลสวน), ภาพเนินในการจำลอง (บอกขอบเขต: ประจุไม่เร่งลงเนิน เพราะชนตลอด และ “ความสูง” คือพลังงานต่อประจุ); กล่องตรวจทาน 4 กล่องตรงตามสเปก §6.2 (ใช้หมดไปตามทาง / จ่ายกระแสคงที่ / ε กับ V เท่ากันเสมอ / เร็วเท่าแสง) ตัวอย่างสตาร์ตรถทำให้ไฟหน้าหรี่ (กระแสสูง V ที่ขั้วตก) ถูกต้อง; ลิงก์ไป estat s4 |
| s2 ความต้านทานและกฎของโอห์ม | F: ผู้เรียนอ่าน \(R = V/I\) แบบพีชคณิตว่า R ขึ้นกับ V จึงเทียบกับ \(E = F/q\) ที่ผู้เรียนเจอแล้วในไฟฟ้าสถิต และให้ตัวอย่างนิโครมที่ V สองเท่าแต่ R เท่าเดิม; แยก “นิยาม R = V/I (ใช้ได้ทุกจุด)” กับ “เป็นไปตามกฎของโอห์ม (R คงที่)” · E: โอห์ม ค.ศ. 1827, แกนกราฟระบุชัด (V แกนตั้ง ความชัน = R), แอมมิเตอร์อนุกรม R น้อย / โวลต์มิเตอร์ขนาน R สูง, \(R = \rho L/A\), นิโครม ρ สูงกว่าทองแดง “หลายสิบเท่า” (1.1×10⁻⁶ / 1.7×10⁻⁸ ≈ 65 ไม่ใส่ตัวเลขเพราะกติกาสภาพต้านทาน), โลหะร้อน R เพิ่ม, หลอดไส้ร้อนกว่า 2,000 °C กราฟโค้งชันขึ้น, \(I = \varepsilon/(R + r)\) และลัดวงจร \(\varepsilon/r\) ยืนยัน; ย้าย \(I = \varepsilon/(R+r)\) มาไว้ s2 (ไม่ใช่ s1) เพราะต้องใช้ \(V = IR\) ก่อน; รอบตรวจที่ 2: เติม “(แกนแบบเดียวกับข้างบน)” ให้คำว่า “ชันขึ้น” มีความหมายเดียว; กล่องตรวจทาน 2 กล่องตามสเปก (R ขึ้นกับ V หรือ I / โอห์มเป็นกฎของทุกสิ่ง) |
| s3 วงจรอนุกรมและขนาน | F: ผู้เรียนจำสูตรสลับกับตัวเก็บประจุที่เพิ่งเรียน จึงให้เหตุผลจากรูปร่าง (ลวดยาวขึ้น/อ้วนขึ้น เทียบแผ่นห่างขึ้น/ใหญ่ขึ้น) ในตารางเดียว และบอกว่าทุกสาขาขนานยังมีกระแส (ไม่ได้ “ไปทางที่ต้านน้อยทั้งหมด”) · E: อนุกรม I เท่ากัน V แบ่ง \(R = \sum R_i\) มากกว่าตัวมากสุด; ขนาน V เท่ากัน (สายศักย์เท่ากันตลอด = ตัวนำชิ้นเดียวใน estat) I แบ่ง \(1/R = \sum 1/R_i\) น้อยกว่าตัวน้อยสุด, สองตัว \(R_1R_2/(R_1+R_2)\); ลัดวงจร: สองปลายศักย์เท่ากัน ไม่มีกระแสผ่านอุปกรณ์, ลัดขั้วแบตเตอรี่ \(\varepsilon/r\) ร้อนจัด, ฟิวส์ (ไม่เอ่ยเบรกเกอร์ซึ่งมีกลไกแม่เหล็ก); หลอดเหมือนกัน: อนุกรมได้ V ครึ่งเดียว “กระแสน้อยลง” (ไม่เขียน “ครึ่งหนึ่ง” เพราะไส้หลอดที่เย็นกว่ามี R ต่ำลง กระแสจึงมากกว่าครึ่ง) ขนานสว่างเท่าหลอดเดียว แบตเตอรี่จ่ายสองเท่า ยืนยัน; อุปมาประตูสนามกีฬา บอกขอบเขต (คนเลือกประตูเอง/ยืนออ แต่ประจุไม่สะสมและไม่ “เลือก” สาขา แบ่งตาม V/R); กล่องตรวจทาน 3 กล่องตามสเปก (ขนานเพิ่มแล้ว R รวมเพิ่ม / หลอดแรกใช้กระแสก่อน / สลับสูตรกับตัวเก็บประจุ); ลิงก์ไป estat s5 |
| s4 กฎของเคอร์ชอฟฟ์ | F: จุดที่ผู้เรียนพลาดคือเครื่องหมาย จึงให้ตารางสี่แถว (R ตาม/ทวนทิศกระแส, ε จาก −→+ / +→−) และย้ำว่าเครื่องหมายของ ε ไม่ขึ้นกับทิศกระแส ขั้นตอน 5 ขั้นจบที่ “อ่านเครื่องหมาย”; ตัวอย่างแรกตั้งใจสมมุติทิศผิดให้เห็นค่าลบ · E: กฎจุดต่อ = อนุรักษ์ประจุ, กฎวงรอบ = ศักย์มีค่าเดียว (ลิงก์ estat s4) = อนุรักษ์พลังงาน, แบตเตอรี่ถูกอัดประจุ \(V = \varepsilon + Ir\) ยืนยัน; เคอร์ชอฟฟ์ ค.ศ. 1845 ถูกต้อง; รอบตรวจที่ 2: ประโยคเดิม “พลังงานที่ได้จากแบตเตอรี่ = พลังงานที่เสียในตัวต้านทาน” ไม่จริงเมื่อมีแบตเตอรี่ถูกอัดประจุในวง (พลังงานเข้าแบตเตอรี่นั้นด้วย) แก้เป็น “ได้รับระหว่างทาง = เสียไประหว่างทาง”; อุปมาเดินภูเขา บอกขอบเขต (เดินได้เฉพาะตามสาย, ความสูง = ศักย์); กล่องตรวจทาน 2 กล่องตามสเปก (เครื่องหมายผิดเมื่อวนทวนทิศกระแส / ค่าติดลบ “แปลว่าทำไม่ได้”); รูปวงจรสองวงรอบเป็น SVG ในบรรทัด (`svg.circ`, `currentColor` จึงใช้ได้ทั้งธีมสว่าง/มืด, ปรับขนาดตามกว้าง ไม่ล้นที่ 390 px ตรวจในเทสต์) |
| s5 กำลังไฟฟ้าและวงจร RC | F: ผู้เรียนคิดว่า “วัตต์สูง = กินไฟ = ต้านมาก” จึงบอกว่าใช้ \(I^2R\) เมื่อกระแสเท่ากัน (อนุกรม) และ \(V^2/R\) เมื่อความต่างศักย์เท่ากัน (ขนาน); ผู้เรียนสับสน \(e\) ในเลขชี้กำลังกับประจุมูลฐาน จึงเขียนแยกไว้ชัด; RC อธิบายเชิงเหตุผล (V_C เพิ่ม → แรงดันที่เหลือให้ R + r ลด → กระแสลด → ช้าลง) ก่อนยกผลเฉลย · E: \(P = VI = I^2R = V^2/R\) (จาก \(E_p = qV\) ของ estat), ความร้อนจูล, \(\varepsilon I = VI + I^2r\), กำลังสูงสุดที่ \(R = r\) ประสิทธิภาพ 50% (ยกมา ไม่พิสูจน์; Python หาค่าสูงสุดแบบไล่ค่าได้ R = r), \(E = Pt\), 1 kWh = 3.6×10⁶ J, ชาร์จ \(q = Q(1 - e^{-t/\tau})\), \(Q = C\varepsilon\), \(\tau = (R + r)C\), \(i = \frac{\varepsilon}{R+r}e^{-t/\tau}\); คาย \(q = Q_0e^{-t/\tau}\), \(\tau = RC\); หน่วย Ω·F = s; ตาราง t = τ, 2τ, 3τ, 5τ (0.63/0.37, 0.86/0.14, 0.95/0.05, 0.993/0.007) ตรวจด้วย Python; เส้นสัมผัสที่ t = 0 ถึง Q ที่ t = τ พอดี; ครึ่งเวลา \(\tau\ln2 \approx 0.69\tau\) เชื่อมครึ่งชีวิต ยืนยัน; ตัวอย่างค่าไฟไม่อ้างไฟบ้าน 220 V/กระแสสลับ (เลี่ยงความรู้บทหลัง) ใช้แค่ P กับ t; อุปมาเติมลมยาง บอกขอบเขต (ยางมีลมเพิ่มจริงแต่ตัวเก็บประจุไม่มีประจุสุทธิเพิ่ม; รูปเอกซ์โพเนนเชียลมาจากสมการวงจร ไม่ใช่จากอุปมา); กล่องตรวจทาน 3 กล่องตามสเปก (หลอดวัตต์สูง R สูง / ชาร์จเต็มทันที / ลดเป็นเส้นตรง); ลิงก์ไป estat s5 และไปข้างหน้าที่ nuclear s3 (ตรวจแล้วว่า `lec-nuclear` `id="s3"` คือ “ครึ่งชีวิต”) |
| ตารางสูตรสำคัญ | F: ผู้เรียนใช้เป็นแผ่นสรุปก่อนทำแบบฝึกหัด จึงแยก τ ของการชาร์จกับการคายไว้คนละบรรทัด และใส่ค่าที่ t = τ · E: ทุกสูตรตรงกับเนื้อหาในบท ไม่มีสูตรที่บทไม่ได้สอน |

## ตัวอย่างโจทย์ในบทเรียน (เปิดทีละขั้น · `lec-circuit`)

ตัวอย่างละหนึ่งบรรทัด ตัวเลขทุกข้อคำนวณซ้ำด้วย Python (`python -I .superpowers/sdd/2026-11-23-circuits-chapter/task-4-arith.py`, 118 รายการผ่านทั้งหมด) โดยใช้ทางที่ต่างจากขั้นในบทเรียนเมื่อทำได้ (ศักย์ของโหนดแทนสมการวงรอบ, อินทิเกรตเชิงตัวเลขของ \(dq/dt\) แทนสูตรสำเร็จ, ไล่ค่าหา R ที่ให้กำลังสูงสุด) และตรวจว่าค่าที่ “ลองในการจำลอง” ตั้งได้จริงด้วยสไลเดอร์ (R ลอการิทึม 2 หลักสำคัญ, r ทีละ 0.05 Ω, ε ทีละ 0.5 V, C ลอการิทึม) · ทดสอบเปิดครบทุกขั้นที่จอ 390 px แล้วไม่ล้น ไม่มี MathJax error (`test_lecture_content` ใน `tests/e2e/test_circuit.py`)
