# บันทึกตรวจเนื้อหา · แบบฝึกหัดคลื่นแม่เหล็กไฟฟ้า (em)

วิธีตรวจของเจ้าของ: อธิบายแบบ Feynman ในมุมผู้เรียน → ผู้เชี่ยวชาญตรวจกับฟิสิกส์ที่ยอมรับ → แก้และวนซ้ำ
ข้อละหนึ่งบรรทัด: **F** = สิ่งที่การอธิบายในมุมผู้เรียนเผยให้เห็น · **E** = สิ่งที่ผู้เชี่ยวชาญยืนยัน/แก้
คำตอบระดับ 2–3 ตรวจซ้ำแยกอิสระด้วย `tests/practice-ref/compute_em.py` ซึ่งใช้เส้นทางคนละแบบกับ JS: ความยาวคลื่น = ระยะที่คลื่นเดินในหนึ่งคาบ (\(cT\)); พลังงานโฟตอนจาก \(hf\) ด้วยค่า \(h\) และ \(e\) ของ CODATA (ไม่ใช้ทางลัด 1240 eV·nm); \(B_0\) จากกฎของฟาราเดย์ \(\partial B/\partial t = -\partial E/\partial x\) (\(B_0 = E_0k/\omega\) โดยหาอนุพันธ์เชิงตัวเลข) ไม่ใช่ \(E_0/c\); ความเข้ม = \(c\varepsilon_0\langle E^2\rangle\) เฉลี่ยตามเวลาเชิงตัวเลข ไม่ใช่สูตร \(\tfrac12 c\varepsilon_0E_0^2\); แสงไม่โพลาไรซ์ = ค่าเฉลี่ยของทิศการสั่นจำนวนมาก แต่ละแผ่นเก็บเฉพาะเงาของเวกเตอร์สนามบนแกน (ไม่ใช้ \(I_0/2\) หรือ \(\cos^2\)); โจทย์ย้อนกลับ (มุมจากร้อยละที่ผ่าน, \(E_0\) จากความเข้ม) ใช้การแบ่งครึ่งช่วงบนแบบจำลองไปข้างหน้า; em-3-04 จำลอง E และ B ที่เฟสตรงกันแล้วแบ่งครึ่งช่วงหาคาบที่ทำให้ B เป็นศูนย์ครั้งแรกตรงเวลาที่วัด
ขอบเขต: ใช้เฉพาะสิ่งที่ `lec-em` สอน: ประจุที่มีความเร่งแผ่คลื่น, ไม่ต้องมีตัวกลาง, \(c = 1/\sqrt{\mu_0\varepsilon_0}\), \(\vec E\perp\vec B\perp\) ทิศคลื่น, ทิศ \(\vec E\times\vec B\), เฟสตรงกัน, \(E = cB\), \(c = f\lambda\), \(E = hf = hc/\lambda \approx 1240\ \text{eV·nm}/\lambda\), ตารางสเปกตรัม, \(I_1 = \tfrac12 I_0\), กฎของมาลุส, ความเข้ม = กำลังต่อพื้นที่ \(= \tfrac12 c\varepsilon_0E_0^2\), ความเข้มมากขึ้น = โฟตอนมากขึ้น · ไม่ใช้โมเมนตัม/ความดันของแสง, การแผ่ทรงกลม \(4\pi r^2\), ตัวกลางที่มี \(\varepsilon \ne \varepsilon_0\), สายอากาศ \(\lambda/4\) (บทเรียนไม่ได้สอน)
ค่าคงที่ที่ระบุในโจทย์ทุกข้อที่ใช้: \(c = 3.0\times10^8\) m/s, \(\varepsilon_0 = 8.85\times10^{-12}\) C²/(N·m²), \(h = 6.63\times10^{-34}\) J·s, \(hc \approx 1240\) eV·nm
คำตอบทุกข้อใช้หน่วยสะดวก (m, eV, µT, W/m², นาที, องศา, V/m, cm, mW, รอบ, ×10¹⁵ โฟตอน/s) จึงไม่มีข้อใดต้องพิมพ์เลขยกกำลัง (ไม่ต้องมีคำใบ้ “พิมพ์แบบ 1.23e-15”); ตัวเลขใหญ่/เล็กภายในสมการใช้ `tex()` ไม่ใช้ `fmt()`; ตรวจ 20 000 ชุดต่อข้อระดับ 2: คำตอบอยู่ใน `range` และ mistake ห่างคำตอบ/ห่างกันเอง ≥ 5.8%; สมการในวิธีทำและคำใบ้ทุกข้อแบ่งท่อนจนไม่ล้นกรอบที่จอ 390 px (สคริปต์เปิดคำใบ้และวิธีทำทุกข้อ ทุกระดับ 3 รอบสุ่ม; รอบแรกพบ 2-05, 3-01, 3-02, 3-03 ล้น จึงแบ่งท่อน)
