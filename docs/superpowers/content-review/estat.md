# บันทึกตรวจเนื้อหา · ไฟฟ้าสถิต (estat)

วิธีตรวจของเจ้าของ: อธิบายแบบ Feynman ในมุมผู้เรียน → ผู้เชี่ยวชาญตรวจกับฟิสิกส์ที่ยอมรับ → แก้และวนซ้ำ
บรรทัดละหนึ่งเรื่อง: **F** = สิ่งที่การอธิบายในมุมผู้เรียนเผยให้เห็น · **E** = สิ่งที่ผู้เชี่ยวชาญยืนยัน/แก้
ค่าคงที่ที่ใช้ทั้งบท (ระบุในโจทย์ทุกข้อที่ใช้): \(k = 9.0\times10^9\) N·m²/C², \(e = 1.6\times10^{-19}\) C, \(m_e = 9.11\times10^{-31}\) kg, \(m_p = 1.67\times10^{-27}\) kg, \(\varepsilon_0 = 8.85\times10^{-12}\) C²/(N·m²)
ขอบเขต: ไม่ใช้ไฟฟ้ากระแส (ไม่มี \(I\), กฎของโอห์ม, วงจร) และไม่ใช้แม่เหล็ก ไม่มีกฎของเกาส์หรือแคลคูลัส · "ชาร์จ" และ "สายดิน" ใช้ในความหมายประจุไหลเท่านั้น

## บทเรียน (`lec-estat`)

| หัวข้อ | บันทึก |
|---|---|
| s1 ประจุไฟฟ้า | F: ผู้เรียนนึกภาพ "ประจุบวกไหล" เพราะได้ยินคำว่าวัตถุ "ได้ประจุบวก" จึงเขียนตั้งแต่ย่อหน้าแรกว่าโปรตอนติดอยู่ในนิวเคลียส และวัตถุเป็นบวกเพราะ*เสีย*อิเล็กตรอน; การเหนี่ยวนำเป็นจุดที่ผู้เรียนงงที่สุด จึงใช้ตาราง 3 วิธี + กล่อง Feynman "ฝูงปลาในตู้" ที่เล่าลำดับ (เข้าใกล้ → ต่อดิน → ตัดดิน → เอาแท่งออก) · E: \(q = ne\), กฎอนุรักษ์ประจุ, ทรงกลมเหมือนกันแบ่งครึ่ง, อิเล็กโทรสโคปกางเพราะการเหนี่ยวนำดันประจุชนิดเดียวกับแท่งลงแผ่น (ทั้งแท่งบวกและแท่งลบ) ยืนยัน; กล่องตรวจทาน 2 กล่องตรงตามสเปก (ประจุบวกเคลื่อนที่ในโลหะ / เหนี่ยวนำโดยไม่ต่อดินได้ประจุสุทธิ) |
| s2 กฎของคูลอมบ์ | F: ผู้เรียนใส่เครื่องหมายของ \(q\) ลงในสูตรแล้วใช้เป็น "ทิศ" จึงเขียนสูตรเป็นขนาด \(|q_1q_2|\) และบอกให้ตัดสินทิศจาก "ผลักหรือดูด" ก่อนรวมเวกเตอร์ · E: \(k = 1/4\pi\varepsilon_0 = 8.99\times10^9\) (ปัดเป็น 9.0) ยืนยัน และแนะนำ \(\varepsilon_0\) ไว้ล่วงหน้าสำหรับ s5; \(F_e/F_g = ke^2/(Gm_em_p) = 2.27\times10^{39}\) (Python, \(G = 6.67\times10^{-11}\)) ยืนยัน; ระบุ "ประจุจุด"; เหตุผลที่ไม่รู้สึกแรงไฟฟ้าในชีวิตประจำวัน (สสารเป็นกลาง) ถูกต้อง; กล่องตรวจทาน: กฎข้อสาม (ประจุใหญ่ออกแรงมากกว่า) และลืมยกกำลังสอง |
| s3 สนามไฟฟ้า | F: "\(E = F/q\) ดังนั้น q ใหญ่ E ก็เปลี่ยน" เป็นการอ่านสูตรตามตัวอักษร จึงอธิบายว่า F เพิ่มตาม q อัตราส่วนเท่าเดิม; ผู้เรียนคิดว่าเส้นสนาม = เส้นทางวิ่งของประจุ จึงแยก "ทิศของแรง" กับ "ทิศของความเร็ว" ด้วยลูกบอลที่ขว้างออกไป · E: นิยามประจุทดสอบ (บวก เล็กมาก), \(E = k|Q|/r^2\) ทิศออก/เข้า, กฎ 4 ข้อของเส้นสนาม, สนามสม่ำเสมอระหว่างแผ่นขนานยกเว้นใกล้ขอบ, \(a = qE/m\) และพาราโบลาแบบโปรเจกไทล์ ยืนยัน; ลิงก์ไปการจำลอง (ฉากไดโพลและแผ่นขนานมีจริงใน `efield.js`) |
| s4 ศักย์และความต่างศักย์ | F: ผู้เรียนสับสนระหว่าง "งานที่เราทำ" (นิยาม \(V = W/q\)) กับ "งานของแรงไฟฟ้า" (\(W_{A\to B} = q(V_A - V_B)\)) จึงเขียนแยกชัดว่า W ตัวไหนคืองานของใคร; ใช้อุปมา "ความสูง" (ก้อนหิน + กล่อง Feynman ภูมิประเทศ) · E: \(V = kQ/r\) ใส่เครื่องหมาย รวมแบบสเกลาร์, \(E = V/d\) (V/m = N/C), สนามชี้จากศักย์สูงไปต่ำ, ผิวศักย์เท่าตั้งฉากเส้นสนาม, **\(\Delta E_k = qV\) โดย \(V = V_A - V_B\)** (ตรวจเครื่องหมาย: อิเล็กตรอนไปหาศักย์สูง \(q<0, V<0\) → \(\Delta E_k>0\) ✓), \(\tfrac12mv^2 = |q|V\) และ **นิยาม eV** \(= 1.6\times10^{-19}\) J ตามที่บทอะตอมต้องใช้ (เชื่อมกับศักย์หยุดยั้ง \(eV_s\)) ยืนยัน; รอบตรวจที่ 2 (ผู้ตรวจ): "ผิวศักย์เท่าชิดกัน = สนามแรง" จริงเฉพาะเมื่อวาดห่างกันทีละ ΔV เท่ากัน เพิ่มเงื่อนไขนั้น; กล่องตรวจทาน: V = 0 ไม่ใช่ E = 0 (ยกไดโพลและคู่ + + ซึ่งตรงกับฉากในการจำลอง: ไดโพล ±2 µC ที่ ±5 cm มี V = 0 และ E = 1.44×10⁷ N/C ที่กึ่งกลาง), รวมศักย์แบบเวกเตอร์, เครื่องหมายงานของประจุลบ |
| s5 ตัวเก็บประจุ | F: ชื่อ "ตัวเก็บประจุ" ทำให้ผู้เรียนคิดว่ามันเก็บประจุสุทธิ จึงเขียน +Q/−Q ตั้งแต่บรรทัดแรก และกล่อง Feynman "สูบน้ำระหว่างถัง" ซึ่งอธิบายที่มาของ ½ ด้วย; สูตรอนุกรม/ขนานให้เหตุผลว่าอะไรเท่ากัน (ประจุบนแผ่นกลางที่โดดเดี่ยว / ตัวนำชิ้นเดียวศักย์เท่ากัน) แทนการท่องจำ · E: \(C = Q/V\), \(C = \varepsilon_0A/d\), \(U = \tfrac12QV = \tfrac12CV^2 = Q^2/2C\) (เฉลี่ยผ่าน V/2 = พื้นที่สามเหลี่ยมใต้กราฟ Q–V) ยืนยัน; รอบตรวจที่ 2 (ผู้ตรวจ): เหตุผลเดิม "แผ่นชิดขึ้น ประจุดึงกันแรงขึ้น C จึงมากขึ้น" ไม่ใช่เหตุผลเชิงปริมาณ แก้เป็น "ประจุเท่าเดิม สนาม \(Q/\varepsilon_0A\) อ่อนลงเมื่อแผ่นใหญ่ และ \(V = Ed\) สั้นลงเมื่อแผ่นชิด → V น้อยลง C = Q/V มากขึ้น" ซึ่งใช้แค่ s4; คำเตือนเรื่องสลับกับตัวต้านทานเขียนเป็นข้อควรระวังเท่านั้น ไม่ใช้สูตรตัวต้านทาน (ตามขอบเขต) |
| การ์ดท้ายบท | F: ผู้เรียนใช้การ์ดเป็นแผ่นสรุปก่อนทำแบบฝึกหัด จึงใส่ \(\Delta E_k = qV\) และ eV แยกบรรทัด · E: ทุกสูตรตรงกับเนื้อหาในบท ไม่มีสูตรที่บทไม่ได้สอน |
