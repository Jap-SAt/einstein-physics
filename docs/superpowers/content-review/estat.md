# บันทึกตรวจเนื้อหา · ไฟฟ้าสถิต (estat)

วิธีตรวจของเจ้าของ: อธิบายแบบ Feynman ในมุมผู้เรียน → ผู้เชี่ยวชาญตรวจกับฟิสิกส์ที่ยอมรับ → แก้และวนซ้ำ
บรรทัดละหนึ่งเรื่อง: **F** = สิ่งที่การอธิบายในมุมผู้เรียนเผยให้เห็น · **E** = สิ่งที่ผู้เชี่ยวชาญยืนยัน/แก้
ค่าคงที่ที่ใช้ทั้งบท (ระบุในโจทย์ทุกข้อที่ใช้): \(k = 9.0\times10^9\) N·m²/C², \(e = 1.6\times10^{-19}\) C, \(m_e = 9.11\times10^{-31}\) kg, \(m_p = 1.67\times10^{-27}\) kg, \(\varepsilon_0 = 8.85\times10^{-12}\) C²/(N·m²)
ขอบเขต: ไม่ใช้ไฟฟ้ากระแส (ไม่มี \(I\), กฎของโอห์ม, วงจร) และไม่ใช้แม่เหล็ก ไม่มีกฎของเกาส์หรือแคลคูลัส · "ชาร์จ" และ "สายดิน" ใช้ในความหมายประจุไหลเท่านั้น

## บทเรียน (`lec-estat`)

| s1 ประจุไฟฟ้า | F: ผู้เรียนนึกภาพ "ประจุบวกไหล" เพราะได้ยินคำว่าวัตถุ "ได้ประจุบวก" จึงเขียนตั้งแต่ย่อหน้าแรกว่าโปรตอนติดอยู่ในนิวเคลียส และวัตถุเป็นบวกเพราะ*เสีย*อิเล็กตรอน; การเหนี่ยวนำเป็นจุดที่ผู้เรียนงงที่สุด จึงใช้ตาราง 3 วิธี + กล่อง Feynman "ฝูงปลาในตู้" ที่เล่าลำดับ (เข้าใกล้ → ต่อดิน → ตัดดิน → เอาแท่งออก) · E: \(q = ne\), กฎอนุรักษ์ประจุ, ทรงกลมเหมือนกันแบ่งครึ่ง, อิเล็กโทรสโคปกางเพราะการเหนี่ยวนำทำให้แผ่นมีประจุชนิดเดียวกับแท่ง ยืนยัน; รอบตรวจที่ 3 (ผู้ตรวจ): ถ้อยคำเดิม "ดันประจุชนิดเดียวกับวัตถุลงไปที่แผ่น" ฟังเหมือนประจุบวกเคลื่อนที่ในโลหะ (ขัดกับกล่องตรวจทานข้างล่าง) แก้เป็นอิเล็กตรอนทั้งสองกรณี: แท่งลบผลักอิเล็กตรอนลงแผ่น แท่งบวกดึงอิเล็กตรอนขึ้นปุ่ม แผ่นจึงขาดอิเล็กตรอน; รอบตรวจที่ 3: ย่อหน้านำเดิมว่าประกายไฟและฟ้าผ่า "มาจากแรงระหว่างประจุที่อยู่นิ่ง" ไม่แม่น (เป็นการไหลออกของประจุที่สะสมอยู่นิ่ง) แก้ตามนั้น; กล่องตรวจทาน 2 กล่องตรงตามสเปก (ประจุบวกเคลื่อนที่ในโลหะ / เหนี่ยวนำโดยไม่ต่อดินได้ประจุสุทธิ) |
| s2 กฎของคูลอมบ์ | F: ผู้เรียนใส่เครื่องหมายของ \(q\) ลงในสูตรแล้วใช้เป็น "ทิศ" จึงเขียนสูตรเป็นขนาด \(|q_1q_2|\) และบอกให้ตัดสินทิศจาก "ผลักหรือดูด" ก่อนรวมเวกเตอร์ · E: \(k = 1/4\pi\varepsilon_0 = 8.99\times10^9\) (ปัดเป็น 9.0) ยืนยัน และแนะนำ \(\varepsilon_0\) ไว้ล่วงหน้าสำหรับ s5; \(F_e/F_g = ke^2/(Gm_em_p) = 2.27\times10^{39}\) (Python, \(G = 6.67\times10^{-11}\)) ยืนยัน; ระบุ "ประจุจุด"; เหตุผลที่ไม่รู้สึกแรงไฟฟ้าในชีวิตประจำวัน (สสารเป็นกลาง) ถูกต้อง; กล่องตรวจทาน: กฎข้อสาม (ประจุใหญ่ออกแรงมากกว่า) และลืมยกกำลังสอง |
| s3 สนามไฟฟ้า | F: "\(E = F/q\) ดังนั้น q ใหญ่ E ก็เปลี่ยน" เป็นการอ่านสูตรตามตัวอักษร จึงอธิบายว่า F เพิ่มตาม q อัตราส่วนเท่าเดิม; ผู้เรียนคิดว่าเส้นสนาม = เส้นทางวิ่งของประจุ จึงแยก "ทิศของแรง" กับ "ทิศของความเร็ว" ด้วยลูกบอลที่ขว้างออกไป · E: นิยามประจุทดสอบ (บวก เล็กมาก), \(E = k|Q|/r^2\) ทิศออก/เข้า, กฎ 4 ข้อของเส้นสนาม, สนามสม่ำเสมอระหว่างแผ่นขนานยกเว้นใกล้ขอบ, \(a = qE/m\) และพาราโบลาแบบโปรเจกไทล์ ยืนยัน; ลิงก์ไปการจำลอง (ฉากไดโพลและแผ่นขนานมีจริงใน `efield.js`) · รอบตรวจที่ 3: ข้อความ "บทที่ NN" ในบทเรียนอื่นที่ค้างจากการเลื่อนเลขบท (lec-mech เรียกบทอนุภาคว่า 04, lec-waves เรียกคลื่น EM ว่า 05) แก้เป็น 05/06 พร้อมชื่อบท และเพิ่มเทสต์ `test_lecture_chapter_numbers_match_mods` |
| s4 ศักย์และความต่างศักย์ | F: ผู้เรียนสับสนระหว่าง "งานที่เราทำ" (นิยาม \(V = W/q\)) กับ "งานของแรงไฟฟ้า" (\(W_{A\to B} = q(V_A - V_B)\)) จึงเขียนแยกชัดว่า W ตัวไหนคืองานของใคร; ใช้อุปมา "ความสูง" (ก้อนหิน + กล่อง Feynman ภูมิประเทศ) · E: \(V = kQ/r\) ใส่เครื่องหมาย รวมแบบสเกลาร์, \(E = V/d\) (V/m = N/C), สนามชี้จากศักย์สูงไปต่ำ, ผิวศักย์เท่าตั้งฉากเส้นสนาม, **\(\Delta E_k = qV\) โดย \(V = V_A - V_B\)** (ตรวจเครื่องหมาย: อิเล็กตรอนไปหาศักย์สูง \(q<0, V<0\) → \(\Delta E_k>0\) ✓), \(\tfrac12mv^2 = |q|V\) และ **นิยาม eV** \(= 1.6\times10^{-19}\) J ตามที่บทอะตอมต้องใช้ (เชื่อมกับศักย์หยุดยั้ง \(eV_s\)) ยืนยัน; รอบตรวจที่ 3 (ผู้ตรวจ): ใช้ \(W\) ในสองความหมาย (งานที่เราทำในนิยาม \(V = W/q\) กับงานของแรงไฟฟ้า) จึงระบุในนิยามว่าเป็นงานที่*เรา*ทำ ใช้ \(W_{A\to B}\) สำหรับงานของแรงไฟฟ้าทุกที่ (รวมกล่องตรวจทาน) และเพิ่ม "งานที่เราทำ = − งานของแรงไฟฟ้า"; เพิ่มหมายเหตุ "V คือความต่างศักย์" ใต้ \(E = V/d\) และ \(\Delta E_k = qV\); รอบตรวจที่ 2 (ผู้ตรวจ): "ผิวศักย์เท่าชิดกัน = สนามแรง" จริงเฉพาะเมื่อวาดห่างกันทีละ ΔV เท่ากัน เพิ่มเงื่อนไขนั้น; กล่องตรวจทาน: V = 0 ไม่ใช่ E = 0 (ยกไดโพลและคู่ + + ซึ่งตรงกับฉากในการจำลอง: ไดโพล ±2 µC ที่ ±5 cm มี V = 0 และ E = 1.44×10⁷ N/C ที่กึ่งกลาง), รวมศักย์แบบเวกเตอร์, เครื่องหมายงานของประจุลบ |
| s5 ตัวเก็บประจุ | F: ชื่อ "ตัวเก็บประจุ" ทำให้ผู้เรียนคิดว่ามันเก็บประจุสุทธิ จึงเขียน +Q/−Q ตั้งแต่บรรทัดแรก และกล่อง Feynman "สูบน้ำระหว่างถัง" ซึ่งอธิบายที่มาของ ½ ด้วย; สูตรอนุกรม/ขนานให้เหตุผลว่าอะไรเท่ากัน (ประจุบนแผ่นกลางที่โดดเดี่ยว / ตัวนำชิ้นเดียวศักย์เท่ากัน) แทนการท่องจำ · E: \(C = Q/V\), \(C = \varepsilon_0A/d\), \(U = \tfrac12QV = \tfrac12CV^2 = Q^2/2C\) (เฉลี่ยผ่าน V/2 = พื้นที่สามเหลี่ยมใต้กราฟ Q–V) ยืนยัน; รอบตรวจที่ 2 (ผู้ตรวจ): เหตุผลเดิม "แผ่นชิดขึ้น ประจุดึงกันแรงขึ้น C จึงมากขึ้น" ไม่ใช่เหตุผลเชิงปริมาณ แก้เป็น "ประจุเท่าเดิม สนาม \(Q/\varepsilon_0A\) อ่อนลงเมื่อแผ่นใหญ่ และ \(V = Ed\) สั้นลงเมื่อแผ่นชิด → V น้อยลง C = Q/V มากขึ้น" ซึ่งใช้แค่ s4; คำเตือนเรื่องสลับกับตัวต้านทานเขียนเป็นข้อควรระวังเท่านั้น ไม่ใช้สูตรตัวต้านทาน (ตามขอบเขต); การอ้างถึงบทไฟฟ้ากระแสคงไว้ (ผู้ควบคุมตัดสิน: เป็นบทถัดไปที่วางแผนไว้) |
| การ์ดท้ายบท | F: ผู้เรียนใช้การ์ดเป็นแผ่นสรุปก่อนทำแบบฝึกหัด จึงใส่ \(\Delta E_k = qV\) และ eV แยกบรรทัด · E: ทุกสูตรตรงกับเนื้อหาในบท ไม่มีสูตรที่บทไม่ได้สอน |

## แบบฝึกหัด (`PRACTICE.estat` · `assets/js/data/practice/estat.js`)

ข้อละหนึ่งบรรทัด: **F** = สิ่งที่การอธิบายในมุมผู้เรียนเผยให้เห็น · **E** = สิ่งที่ผู้เชี่ยวชาญยืนยัน/แก้
คำตอบระดับ 2–3 ตรวจซ้ำแยกอิสระด้วย `tests/practice-ref/compute_estat.py` ซึ่งไม่ใช้สูตรเดียวกับ JS: ประจุเวลาทรงกลมแตะกันนับเป็นจำนวนอิเล็กตรอน (เศษส่วนแม่นตรง), แรงและสนามรวมเป็น<b>เวกเตอร์คูลอมบ์สามมิติ</b> \(kq_1q_2(\vec r_2-\vec r_1)/|\vec r_2-\vec r_1|^3\) (ไม่ใช่ “ขนาดแล้วตัดสินทิศ”), จุดสนามเป็นศูนย์หาด้วยการแบ่งครึ่งช่วงบนสนามที่มีเครื่องหมาย, งานคิดด้วยการอินทิเกรตเชิงตัวเลขผ่านสนามสม่ำเสมอที่สร้างจากศักย์สองจุด, ความต่างศักย์เร่งและการเบนในแผ่นขนานได้จากการจำลองกฎข้อที่ 2 ของนิวตัน (velocity Verlet) แล้วแบ่งครึ่งช่วงเมื่อโจทย์ถามย้อน, ประจุบนแผ่นคิดจาก \(\sigma = \varepsilon_0E\) กับ \(E = V/d\) (ไม่ใช้ \(C = \varepsilon_0A/d\)), วงจรตัวเก็บประจุแก้ด้วยประจุรวมศูนย์ของตัวนำกลางที่โดดเดี่ยว (ศักย์ของจุดต่อ) และพลังงานเป็นผลรวม \(Q^2/2C\) ของแต่ละตัว
ค่าคงที่ที่ระบุในโจทย์ทุกข้อที่ใช้ (เท่ากับบทเรียน): \(k = 9.0\times10^9\) N·m²/C², \(e = 1.6\times10^{-19}\) C, \(m_e = 9.11\times10^{-31}\) kg, \(m_p = 1.67\times10^{-27}\) kg, \(\varepsilon_0 = 8.85\times10^{-12}\) C²/(N·m²), \(g = 9.8\) m/s² · เครื่องหมายตามบทเรียน: \(W_{A\to B} = q(V_A - V_B)\) คืองานของ<em>แรงไฟฟ้า</em>, งานที่เราทำ = − งานของแรงไฟฟ้า, \(V\) ใน \(E = V/d\) และ \(\Delta E_k = qV\) คือความต่างศักย์ · ไม่ใช้ไฟฟ้ากระแส แม่เหล็ก กฎของเกาส์ (ในโจทย์) หรือแคลคูลัส
`signed: true` ทุกข้อที่คำตอบหรือค่าความผิดติดลบได้ หรือเครื่องหมายเป็นประเด็นของคำตอบ (2-01, 2-02, 2-04, 3-02, 3-03); ข้อสุ่มทุกข้อใช้ `apart()` คัดชุดตัวเลขที่ค่าความผิดอยู่ห่างคำตอบและห่างกันเอง ≥ 8% (ตรวจ 20 000 ชุด: ห่างกันน้อยที่สุด 8.3%) จึงบอกได้เสมอว่าผู้เรียนผิดแบบไหน · สมการในวิธีทำ คำใบ้ และข้อความความผิดทุกข้อแบ่งท่อนจนไม่ล้นกรอบที่จอ 390 px (ตรวจด้วยสคริปต์ Playwright ที่เปิดทุกข้อ ทุกตัวลวงของระดับ 1 และระดับ 2 หลายชุดตัวเลข: ไม่มี MathJax error, ไม่มี `undefined`/`NaN`, ไม่มีสมการล้นกรอบ; รอบแรกพบสมการล้น 8 ข้อ เช่น เศษส่วนที่มีสามตัวคูณ แก้โดยแยก \(k\) ออกเป็นท่อนหน้า)
