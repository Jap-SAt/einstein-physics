# บันทึกตรวจเนื้อหา · แบบฝึกหัดอนุภาคมีประจุในสนามแม่เหล็ก (particle)

วิธีตรวจของเจ้าของ: อธิบายแบบ Feynman ในมุมผู้เรียน → ผู้เชี่ยวชาญตรวจกับฟิสิกส์ที่ยอมรับ → แก้และวนซ้ำ
ข้อละหนึ่งบรรทัด: **F** = สิ่งที่การอธิบายในมุมผู้เรียนเผยให้เห็น · **E** = สิ่งที่ผู้เชี่ยวชาญยืนยัน/แก้
คำตอบระดับ 2–3 ตรวจซ้ำแยกอิสระด้วย `tests/practice-ref/compute_particle.py` ซึ่งไม่ใช้สูตรปิด \(r = mv/qB\), \(T = 2\pi m/qB\), \(p = v\cos\theta\,T\) แต่ <b>จำลองการเคลื่อนที่</b> ด้วยกฎข้อที่ 2 ของนิวตันกับแรงลอเรนซ์ \(\vec F = q(\vec E + \vec v\times\vec B)\) แบบเวกเตอร์สามมิติ (Boris integrator) แล้วอ่านคำตอบจากเส้นทาง (จุดที่ไกลที่สุด, เวลาที่ทิศความเร็ววนกลับมาเดิม, ระยะที่เลื่อนตามสนามในหนึ่งรอบ, ตำแหน่งหลังครึ่งรอบพร้อมเครื่องหมาย) ส่วนโจทย์ย้อนกลับ (หา v, m, e/m จากรัศมีที่วัด) ใช้การแบ่งครึ่งช่วงบนการจำลอง และแรงคิดด้วย cross product
บทนี้ยังไม่มีบทไฟฟ้า จึงใช้เฉพาะสิ่งที่บทเรียนให้: \(F = qvB\sin\theta\) กับกฎมือขวา (ประจุลบกลับทิศ), แรงแม่เหล็กไม่ทำงาน, \(r\), \(T\), \(f\), เกลียว, ตัวเลือกความเร็ว \(qE = qvB\) และ \(r \propto m/q\) · ทุกข้อที่มีสนามไฟฟ้าระบุในโจทย์ว่า “\(E\) ออกแรง \(qE\) ต่อประจุ \(q\)” ไม่ใช้ศักย์ไฟฟ้า/การเร่งผ่านความต่างศักย์/อิเล็กตรอนโวลต์ (บทเรียนไม่ได้สอน)
ค่าคงที่ที่ระบุในโจทย์ทุกข้อที่ใช้: \(e = 1.6\times10^{-19}\) C, \(m_e = 9.11\times10^{-31}\) kg, \(m_p = 1.67\times10^{-27}\) kg, \(1\ \text{u} = 1.66\times10^{-27}\) kg · อัตราเร็วทุกข้อไม่เกิน \(10^7\) m/s (ไม่ต้องคิดสัมพัทธภาพ)
