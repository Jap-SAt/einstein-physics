# บันทึกตรวจเนื้อหา · แบบฝึกหัดสสารและอุณหพลศาสตร์ (thermo)

วิธีตรวจของเจ้าของ: อธิบายแบบ Feynman ในมุมผู้เรียน → ผู้เชี่ยวชาญตรวจกับฟิสิกส์ที่ยอมรับ → แก้และวนซ้ำ
ข้อละหนึ่งบรรทัด: **F** = สิ่งที่การอธิบายในมุมผู้เรียนเผยให้เห็น · **E** = สิ่งที่ผู้เชี่ยวชาญยืนยัน/แก้
คำตอบระดับ 2–3 ตรวจซ้ำแยกอิสระด้วย `tests/practice-ref/compute_thermo.py` (ใช้เส้นทางคนละแบบกับ JS เช่น หา \(v_{\text{rms}}\) จาก \(\tfrac32 k_BT\) ต่อโมเลกุล, หาความดันจาก \(PV = Nk_BT\), หาอุณหภูมิผสมด้วยการแบ่งครึ่งช่วง, หาปริมาตรฟองผ่านจำนวนโมล)
ค่าคงที่ตามบทเรียน: \(R = 8.314\) J/(mol·K), \(c\) ของน้ำ 4200 J/(kg·K), \(L_f = 3.34\times10^5\), \(L_v = 2.26\times10^6\) J/kg, \(T(\text{K}) = T(^\circ\text{C}) + 273.15\) — ระบุในโจทย์ทุกข้อที่ใช้
