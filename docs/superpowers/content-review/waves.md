# บันทึกตรวจเนื้อหา · แบบฝึกหัดคลื่นและทัศนศาสตร์ (waves)

วิธีตรวจของเจ้าของ: อธิบายแบบ Feynman ในมุมผู้เรียน → ผู้เชี่ยวชาญตรวจกับฟิสิกส์ที่ยอมรับ → แก้และวนซ้ำ
ข้อละหนึ่งบรรทัด: **F** = สิ่งที่การอธิบายในมุมผู้เรียนเผยให้เห็น · **E** = สิ่งที่ผู้เชี่ยวชาญยืนยัน/แก้
คำตอบระดับ 2–3 ตรวจซ้ำแยกอิสระด้วย `tests/practice-ref/compute_waves.py` (ใช้เส้นทางคนละแบบกับ JS เช่น หามุมหักเหและมุมวิกฤตด้วยการแบ่งครึ่งช่วง, ใช้รูปแบบของนิวตัน \((u-f)(v-f) = f^2\) แทนสูตรเลนส์, หาตำแหน่งแถบสว่างด้วยมุมจริง \(L\tan\theta\) แทนการประมาณมุมเล็ก, นับลำดับของเกรตติงทีละค่า, ใช้หลักของฮอยเกนส์ \(\lambda_1/\sin\theta_1 = \lambda_2/\sin\theta_2\) แทนสเนลล์)
ข้อตกลงตามบทเรียน (s5): ระยะภาพจริงเป็นบวก ระยะภาพเสมือนเป็นลบ เลนส์นูนมี \(f\) เป็นบวก — ระบุในโจทย์ทุกข้อที่ใช้; กระจกใช้ข้อตกลงเดียวกัน (บทเรียนไม่ได้เขียนเครื่องหมายของกระจกตรง ๆ จึงระบุครบในตัวอย่าง s5) · ขนาดภาพใช้ \(|m| = |v|/u\) เพื่อไม่ต้องสอนความหมายของเครื่องหมาย \(m\) ซึ่งบทเรียนไม่ได้กำหนด
ค่าคงที่ที่ระบุในโจทย์: \(c = 3.0\times10^8\) m/s, เสียงในอากาศ 343 m/s, ดรรชนีหักเหของอากาศ 1.00 น้ำ 1.33 อะคริลิก 1.49 แก้ว 1.52 แก้วฟลินต์ 1.66 เพชร 2.42
