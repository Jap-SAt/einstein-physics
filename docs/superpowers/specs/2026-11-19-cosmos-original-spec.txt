ทำหน้าที่เป็น Senior Creative Technologist และ Physics Simulation Engineer จงสร้างเว็บแอปพลิเคชันแบบ Interactive เรื่อง "วิวัฒนาการและการกำเนิดจักรวาล (The Big Bang & Cosmic Evolution)" ในรูปแบบ Single-file React Component (ใช้ Tailwind CSS, Lucide Icons และ HTML5 Canvas API สำหรับเรนเดอร์อนุภาคความเร็วสูง)

### 1. โครงสร้างหน้าจอและ UX/UI (Layout & Aesthetics)
- **สไตล์ภาพ:** ผสมผสานความคมชัดแบบ 3Blue1Brown (เส้นเวกเตอร์เรืองแสง พื้นหลังอวกาศสีดำสนิท #05050A) เข้ากับการไล่ระดับสีและแสงฟุ้ง (Additive Blending / Glow Effects) สไตล์ Kurzgesagt
- **การจัดวาง:** 
  - พื้นที่หลัก (100vw x 100vh) เป็น HTML5 Canvas เต็มหน้าจอที่รองรับการลากเมาส์เพื่อหมุนมุมมอง (2.5D Parallax Tilt) และเลื่อนลูกกลิ้งเพื่อซูมเข้า-ออก (Zoom)
  - ด้านล่างเป็น Control Dock แบบ Glassmorphism โปร่งแสง ประกอบด้วย:
    1. **Cosmic Timeline Slider:** แถบเลื่อนเวลาแบบ Logarithmic ตั้งแต่ 10^-43 วินาที จนถึง 13.8 พันล้านปี
    2. **ปุ่ม Play / Pause** และตัวปรับความเร็ว (1x, 2x, 5x)
    3. **ปุ่มสลับโหมดการแสดงผล (Toggle):** เปิด/ปิด เส้นกริดกาลอวกาศ (Spacetime Grid) และ เปิด/ปิด ป้ายกำกับอนุภาค (Particle Labels)
  - ด้านขวาบนเป็น **HUD (Heads-Up Display)** แสดงค่าตัวแปรทางฟิสิกส์แบบเรียลไทม์ ได้แก่:
    - เวลาหลังเกิดบิ๊กแบง (Time After Big Bang)
    - อุณหภูมิเฉลี่ยของเอกภพ (Temperature in Kelvin - K)
    - ขนาดสัมพัทธ์ (Scale Factor)
    - กล่องคำอธิบายสั้นๆ ของยุคสมัยปัจจุบัน (ภาษาไทยที่เข้าใจง่าย)

### 2. กลไกฟิสิกส์และการแบ่งยุคสมัย (5 Cosmic Epochs)
ให้เขียน Logic ใน Canvas Render Loop (`requestAnimationFrame`) เพื่อเปลี่ยนพฤติกรรมของอนุภาค (จำนวน 800 - 1,200 อนุภาค) ตามช่วงเวลาบน Timeline ดังนี้:

1. **ยุคพลังค์และการพองตัว (Planck & Inflation Epoch: 10^-43 ถึง 10^-32 วินาที)**
   - **ภาพ:** จุดซิงกูลาริตี้สว่างจ้าตรงกลาง ก่อนจะเกิดการขยายตัวแบบทวีคูณ (Exponential Expansion) อย่างฉับพลัน
   - **ฟิสิกส์:** เส้นกริดกาลอวกาศถูกยืดออกอย่างรวดเร็ว อุณหภูมิสูงถึง 10^32 K สีของอนุภาคเป็นสีขาวอมฟ้าพลังงานสูง
2. **ยุคควาร์กและพลาสมา (Quark-Gluon Plasma: 10^-12 ถึง 1 วินาที)**
   - **ภาพ:** อนุภาคขนาดเล็ก (Quarks, Gluons, Electrons) เคลื่อนที่ด้วยความเร็วสูงแบบสุ่ม (Brownian Motion) ชนกันไปมาตลอดเวลา
   - **ฟิสิกส์:** ใช้สีแยกประเภทอนุภาค (เช่น ควาร์กสีแดง/เขียว/น้ำเงิน) พร้อมเส้นเชื่อมแรงนิวเคลียร์อย่างเข้ม (Strong Force) ที่เกิดและดับอย่างรวดเร็วเมื่ออนุภาคเข้าใกล้กัน
3. **ยุคนิวคลีโอซินทีซิส (Nucleosynthesis: 3 นาที ถึง 20 นาที)**
   - **ภาพ:** อุณหภูมิลดลงจนควาร์กรวมตัวกันเป็นโปรตอนและนิวตรอน และจับคู่กันเป็นนิวเคลียสของไฮโดรเจน (75%) และฮีเลียม (25%)
   - **ฟิสิกส์:** อนุภาคเริ่มลดความเร็วลงและจับกลุ่มเป็นคลัสเตอร์ขนาด 2-4 เม็ด (จำลองนิวเคลียส) มีออร่าสีส้ม-ทอง
4. **ยุคการแผ่รังสีพื้นหลัง (Recombination & CMB: 380,000 ปี)**
   - **ภาพ:** อิเล็กตรอนถูกดึงเข้าสู่วงโคจรรอบนิวเคลียส กลายเป็นอะตอมที่เป็นกลาง แสงโฟตอนสามารถเดินทางได้อย่างอิสระ (เกิดแสงวาบไปทั่วทั้งหน้าจอและค่อยๆ จางลงเป็นพื้นหลังสีแดงเข้ม/ส้มคล้ายแผนที่ CMB)
5. **ยุคมืดและการก่อตัวของกาแล็กซี (Dark Ages & Galaxy Formation: 200 ล้านปี - 13.8 พันล้านปี)**
   - **ภาพ:** กลุ่มก๊าซเริ่มยุบตัวด้วยแรงโน้มถ่วง เกิดเป็นดาวฤกษ์รุ่นแรก (สีฟ้าสว่าง) และหมุนวนรวมกันเป็นกาแล็กซีทรงกังหัน (Spiral Galaxies) ที่เคลื่อนที่ห่างออกจากกันตามกฎของฮับเบิล (Hubble's Law: ความเร็วในการเคลื่อนที่ออกแปรผันตามระยะห่างจากจุดศูนย์กลาง)

### 3. ข้อกำหนดทางเทคนิค (Technical Constraints)
- ใช้ `window.devicePixelRatio` เพื่อรองรับหน้าจอความละเอียดสูง (Retina Display) ไม่ให้ภาพแตก
- ป้องกัน Memory Leak โดยการเคลียร์ Animation Frame และ Event Listeners เมื่อ Component Unmount
- เขียนโค้ดให้สมบูรณ์ในไฟล์เดียว สามารถรันได้ทันทีโดยไม่มี Placeholder หรือโค้ดที่ถูกตัดทอน
